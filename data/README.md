# Research data

Each source has its own folder: `reddit/`, `youtube/`, `h1b/`, `university/`, `economic_indicators/`, and `policy_timeline/`. Collection responses and generated outputs stay here, outside `code/`.

The repository includes the aggregate Reddit theme summary, a dashboard-ready set of 189 reviewed Reddit comments with sentiment labels, the source-linked historical university enrollment table, economic indicator tables, and the policy event review list. The dashboard comment file includes only text, date, subreddit, Reddit link, policy event ID, comment ID, and sentiment; it excludes author names and collection metadata. Raw Reddit responses, full reviewed records, YouTube samples, H-1B downloads, and other generated files are local and ignored by Git.
