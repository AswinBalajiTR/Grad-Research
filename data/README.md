# Research data

Each source has its own folder: `reddit/`, `youtube/`, `h1b/`, `university/`, `economic_indicators/`, and `policy_timeline/`. Collection responses and generated outputs stay here, outside `code/`.

The repository includes the aggregate Reddit theme summary, the source-linked historical university enrollment table, economic indicator tables, and the policy event review list. Raw Reddit responses, reviewed comment records, YouTube samples, H-1B downloads, and other generated files are local and ignored by Git.
